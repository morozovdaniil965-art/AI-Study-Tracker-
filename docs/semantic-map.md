dashboard — main. Он содержит всё основное содержимое страницы личного кабинета пользователя.

dashboard__welcome — section. Это блок с приветствием и мотивационной цитатой.

dashboard__stats — section. Она объединяет несколько связанных показателей пользователя, а отдельные карточки статистики — article, потому что каждая карточка представляет самостоятельную информационную единицу.

dashboard__grid — div. Это контейнер, который нужен для построения сетки и расположения основной и правой колонок.

dashboard-card — section. Он содержит отдельную тематическую часть страницы с текущим учебным заданием пользователя. section подходит, потому что блок имеет собственный заголовок.

dashboard-card — section. Он объединяет информацию об учебных направлениях пользователя. Отдельные направления представлены тегом a, так как пользователь может перейти по ним на другую страницу.

statistics — section. Это самостоятельный раздел с графиком учебной активности. Внутренние элементы графика являются div, потому что выполняют техническую функцию построения графика.

dashboard__side — aside. В ней находятся дополнительные блоки AI Coach, достижений и мотивации, которые дополняют основное содержимое страницы, поэтому aside здесь уместен.

ai-card — section. Это отдельный тематический блок с рекомендациями для пользователя. Список рекомендаций оформлен через ul и li, потому что элементы представлены в виде списка.

achievements — section. Блок объединяет несколько достижений пользователя и имеет собственный заголовок. 
Отдельные достижения можно представить как article, поскольку каждое из них является самостоятельной информационной единицей.

motivation — section. Он содержит отдельное тематическое мотивационное сообщение и имеет собственный заголовок.

pro-banner — section. Это самостоятельный информационный блок с описанием возможностей PRO и ссылкой на подробную информацию, поэтому section подходит для его выделения.
