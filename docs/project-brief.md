

Продукт:
AI Study Tracker — веб-приложение для организации обучения, отслеживания прогресса и получения рекомендаций по дальнейшему изучению материала.

Страница:
Страница создания нового направления обучения.

Проблема:
Пользователю необходимо иметь возможность добавлять новые направления обучения, чтобы организовывать учебный процесс и отслеживать прогресс по разным темам.

Пользователь:
Студент или человек, который самостоятельно изучает несколько направлений и хочет организовать их в одном месте.

Основной пользовательский сценарий:
Пользователь переходит в раздел направлений и нажимает кнопку создания нового направления. На странице он вводит название и описание направления, выбирает стандартную иконку или загружает собственную, после чего нажимает кнопку «Создать направление».

Цель страницы:
Дать пользователю простой способ создать новое направление обучения и добавить его в систему.

Основное целевое действие:
Создание нового направления обучения через заполнение формы.

Основные блоки страницы:
- хлебные крошки;
- заголовок и описание страницы;
- форма создания направления;
- название направления;
- описание направления;
- выбор иконки;
- загрузка собственной иконки;
- кнопка создания направления;
- кнопка отмены;
- информационная иллюстрация.
